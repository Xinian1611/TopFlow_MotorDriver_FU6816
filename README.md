------------------------ 前言 -------------------------
- 这是基于FU6866Q1的无感FOC标准汽车电子应用程序  
- 程序以FU6866Q1为参考进行配置，当芯片或硬件修改时，需配对以下参数（详情可参考“参考手册”）：
     1. 驱动有效电平；
     2. 运放放大倍数；
     3. 采样电阻；
     4. 母线电压分压电阻。

--------------------- 适用编译器 ---------------------
- [支持] KeilC51
- [支持] FTCC
---------------------- 程序功能 -----------------------
已支持以下功能：
- 采样模式：单电阻/双/三电阻采样
- 顺逆风检测：BEMF/RSD顺逆风
- 估算器：AO/SMO
- 调速模式：上电运行/PWM调速/VSP调速/启停测试/LIN调速
- 过调制
- 预充电与IPMtest模式
- 预定位
- LIN通信收发
- 保护功能:硬件过流，缺相，堵转，过欠压，NTC过温，MCU过温可触发
- 重启功能:重启次数与时间可设定
- 母线限流
- 弱磁增速
- PWM休眠与唤醒,休眠电流<100uA

---------------------- 适用芯片 -----------------------
1. FU6866Q1
2. FU6816Q1
